# query-bot

让用户在 Lark 中提出问题，通过 PSR 获得可读、可核验的查询结果。

项目复用 LangBot 运行时，以独立插件接入 PSR。首版聚焦一条完整路径：授权用户发送问题，插件调用查询后端，将答案、后端提供的引用和必要查询口径返回原会话；失败时给出明确结果。

**仓库已完成文档初始化，插件实现待开始。**

当前文件定义项目职责、实施入口与验证方式。尚无可运行的 PSR 插件、已验证的运行时版本组合或部署结果。具体接口以实施时核实的版本为准。

## 职责

| 组成 | 职责 |
| --- | --- |
| LangBot | 复用官方消息平台接入、会话和插件运行等通用能力 |
| query-bot | 可复用的 PSR 接入插件、请求与响应转换、可信身份上下文传递、答案/引用/错误呈现 |
| PSR | 查询执行、数据访问权限与业务口径 |
| 环境交付配置 | 实际应用绑定、身份映射、服务地址与凭据引用、部署和真实验收 |

身份映射通过明确接口或配置接入。查询后端负责最终授权判定；聊天文本中的身份声明不能直接作为授权依据。

## 第一步：B0，完成一条真实查询

1. 在已授权环境运行选定版本的 LangBot，连通 Lark。
2. 用已核实的插件接口接入实际 PSR 查询服务。
3. 由已授权测试用户从 Lark 提出一条有业务意义的问题。
4. 将真实结果回送到原会话，保留请求关联及后端提供的引用、查询条件和错误含义。

测试用户可以由执行者或自动化客户端操作，B0 无需等待自然产生的使用量。容器启动、消息回显或模拟结果不能单独证明 B0 通过。

后续按实际范围推进答案核验与追问（B1）、多人及故障处理（B2）；自主规划或多工具执行（B3）由具体新增需求触发。
